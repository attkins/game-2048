# Ideas

Ideas for Game 2048 that are not part of the MVP and have no date. Collected on 2026-11-26.

An idea here has no ID and no promise. When one gets mature, it moves into [backlog.md](backlog.md) with an ID and into a release in [roadmap.md](roadmap.md). Rejected ideas stay here with a short note, so nobody proposes them again.

## From the concept

- Endless mode beyond 2048 with additional chip colors for 4096 and higher (see D-013)
- Win targets that scale with the board size, for example a lower target on 3x3 (see D-011)
- Undo for the last move
- Sound effects for slide, merge and win
- Themes for the board and the chips
- Leaderboards
- Daily challenge with the same start position for everyone
